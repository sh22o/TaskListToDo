## 🚀 Features  
- 📌 **Add Tasks**: Type and add tasks easily.  
- ✅ **Mark as Completed**: Click on a task to mark it as done.  
- ❌ **Delete Tasks**: Click the ❌ button to remove a task.  
- 💾 **Data Persistence**: Tasks are saved using `localStorage` and reload on page refresh.  
- 📱 **Fully Responsive**: Works on all devices (Mobile, Tablet, Desktop).  

---

## 🛠️ Tech Stack  
- **Frontend**:  
  - ✅ HTML5  
  - 🎨 CSS3  
  - ⚡ JavaScript (ES6)  

- **Storage**:  
  - 💾 LocalStorage (to save tasks)

## 🎯 Usage
- Enter a task in the input field.
- Click "Add" to add it to the list.
- Click on a task to mark it as completed.
- Click the ❌ button to delete a task.
- The list is automatically saved and persists after refresh.
